# HR Market Analysis

## 📌 Project Overview

**ACC HireSmart – HR Market Analysis** is a market research and data analytics project focused on identifying and analyzing the skills required across different HR/HRM roles.

The project follows an end-to-end analytics workflow, starting from **data collection and market research** and progressing through **data cleaning, analysis, visualization, and reporting**.

## 🔄 Project Workflow

**Data Collection → Data Cleaning → Skill Categorization → Data Analysis → Dashboard Development → Reporting**

### 🔹 Key Steps

* Collected HR job-market data from **multiple sources** and maintained a source list.
* Organized the collected data into a structured dataset.
* Cleaned and transformed the data using **Power Query in Power BI**.
* Categorized skills into **Functional HR, Technology/Tools, Analytics/Business, and Soft Skills**.
* Analyzed **10 HR roles and 92 identified skills**, including 14 technical skills.
* Created KPIs to summarize the key findings.
* Developed an interactive **Power BI dashboard** with:

  * Top 10 HR Skills
  * Skill Category Distribution
  * Skills by HR Role
  * Interactive Slicers and Filters
 
* Prepared a **Microsoft Word report** documenting the research methodology, sources, analysis, and findings.

## 🎯 Outcome

The project provides an interactive view of the HR hiring market and demonstrates the complete process of converting **raw market research data into structured insights, visualizations, and an analytical dashboard**.
